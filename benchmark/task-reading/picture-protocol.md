# Extension to pictures without a key

Can the same color-to-category decoder find a loss of separability between the marks that carry a picture's message? Test the two unmarked photo sources and the three ordinary/control plates. Exclude reverse plate 19 because the task concerns emergence of a new shape. Use one copy per source.

An annotator chose six locations per class on each original before running this extension. The two classes are numeral stroke/field or target foliage or berries/other foliage. For each of six folds, hold out one location from each class. The coordinate-wise median Lab color of the remaining five locations forms each class prototype. Compute each held-out mark's correct-versus-competing distance margin on the original and each simulation. Use the textbook thresholds of 6 and 12 without refitting.

Among the 12 probes, count the marks originally well separated (margin ≥ 12), and how many of those become weak (margin < 6) under each profile. Report numerator and denominator. An empty denominator is unresolved. Prediction: red–green simulations should cause more originally clear probes to become weak on the two challenge plates than on plate 01. The photos are exploratory. Within-image folds test transfer between selected patches, not between independent photographs. The probe score tests evidence for identifying individual marks. Whole-numeral reading and photo-search success are separate validation outcomes.
